
# Skill: Code Review

## Nombre
code_review

## Objetivo
Analizar código Python para identificar errores
y proponer mejoras.

## Responsabilidades
- Revisar la sintaxis del código.
- Identificar posibles errores.
- Detectar malas prácticas.
- Evaluar la legibilidad.
- Proponer soluciones.

## Instrucciones para el agente
1. Lee el código proporcionado.
2. Identifica los errores encontrados.
3. Explica por qué ocurre cada error.
4. Propone una solución concreta.
5. Presenta una versión corregida del código.

## Restricciones
- No modificar archivos originales.
- No inventar errores.
- Explicar las recomendaciones de forma clara.
